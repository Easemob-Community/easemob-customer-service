# 06 · 接口与数据库设计

## 第一部分 · REST API 规范

### 0. 通用约定

| 项 | 约定 |
|----|------|
| Base URL | 访客端 `/open/**`（guest JWT）；控制台 `/admin/**`（Sa-Token）；回调 `/easemob/callback/**` |
| 响应 | `{ "code": 0, "msg": "ok", "data": {...} }`；code≠0 为业务错误 |
| 认证头 | `Authorization: Bearer <token>` |
| 分页 | `pageNum`（从 1 起）/ `pageSize`（≤100）；返回 `{ total, list }` |
| 时间 | ISO-8601（`2026-08-25T10:00:00+08:00`） |
| 错误码 | 0 成功；4001 AI 账号池空；4002 会话不存在/已关闭；4003 无可用坐席；4010 未认证；4030 无权限；4290 限流 |

### 1. 开放接口（访客端 / App）

#### 1.1 获取访客凭证

`POST /open/auth/guest-token`

```json
// 请求
{ "userId": "user_10001", "nickname": "小明", "channel": "web", "deviceId": "uuid" }
// 响应
{
  "code": 0,
  "data": {
    "token": "guest-jwt...",
    "userId": "user_10001",
    "easemobToken": "easemob-user-token...",
    "expiresIn": 7200
  }
}
```

> 服务端按 userId 幂等创建「用户组」账号，并代申请环信用户 Token。

#### 1.2 发起/恢复会话（主链路入口）

`POST /open/session/start`

```json
// 请求
{ "channel": "web", "skillGroupId": 2, "metadata": { "orderId": "SO123" } }
// 响应
{
  "code": 0,
  "data": {
    "sessionId": "8901",
    "groupId": "251986809421825",
    "status": "AI_SERVING",
    "handlerType": "AI",
    "aiAccount": { "id": "ai_bot_001", "nickname": "智能助手" },
    "welcome": "您好，我是智能客服小环～"
  }
}
```

## 第二部分 · 数据库设计（MySQL 8）

### 1. ER 概览

```
cs_group ──1:N── cs_account（AI组/坐席组/用户组）
cs_account ──1:N── cs_session（user / ai / agent 三个外键）
cs_session ──1:N── cs_message
cs_session ──1:N── cs_transfer_record
cs_session ──1:1── cs_evaluate
cs_familiar_relation（user ↔ agent 熟客）
cs_ai_provider（AI 厂家配置）
cs_assignment_strategy（分配策略）
cs_quick_reply / cs_transfer_word / cs_op_log / cs_stat_daily
```

> 当前未启用（表已建，无业务代码，二期）：`cs_quick_reply`（快捷回复）、`cs_op_log`（操作日志）、`cs_stat_daily`（看板预聚合）；`cs_assignment_strategy` 表已建但代码未读写（策略接口为 stub）。

### 2. 核心 DDL

```sql
-- 组
CREATE TABLE cs_group (
  id          BIGINT PRIMARY KEY AUTO_INCREMENT,
  name        VARCHAR(64)  NOT NULL COMMENT 'A组/B组/AI组',
  type        VARCHAR(16)  NOT NULL COMMENT 'AI/AGENT/USER',
  parent_id   BIGINT       DEFAULT NULL,
  status      TINYINT      NOT NULL DEFAULT 1,
  create_time DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 账号（AI / 用户 / 坐席统一表）
CREATE TABLE cs_account (
  id            BIGINT PRIMARY KEY AUTO_INCREMENT,
  easemob_id    VARCHAR(64)  NOT NULL COMMENT '环信用户ID',
  type          VARCHAR(8)   NOT NULL COMMENT 'AI/USER/AGENT',
  group_id      BIGINT       DEFAULT NULL,
  nickname      VARCHAR(64),
  avatar        VARCHAR(255),
  max_sessions  INT          DEFAULT 5 COMMENT '坐席接待上限',
  status        TINYINT      NOT NULL DEFAULT 1,
  ext_json      JSON         DEFAULT NULL,
  create_time   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_easemob (easemob_id),
  KEY idx_type_group (type, group_id, status)
);

-- 会话（群组即会话）
CREATE TABLE cs_session (
  id                   BIGINT PRIMARY KEY AUTO_INCREMENT,
  group_id             VARCHAR(64) NOT NULL COMMENT '环信群组ID',
  user_account_id      VARCHAR(64) NOT NULL,
  ai_account_id        VARCHAR(64) NOT NULL,
  agent_account_id     VARCHAR(64) DEFAULT NULL,
  status               VARCHAR(16) NOT NULL DEFAULT 'CREATED',
  current_handler_type VARCHAR(8)  NOT NULL DEFAULT 'AI',
  channel              VARCHAR(16),
  skill_group_id       BIGINT,
  transfer_reason      VARCHAR(32) DEFAULT NULL,
  fail_count           INT NOT NULL DEFAULT 0 COMMENT 'AI连续失败次数',
  first_response_ms    INT COMMENT 'AI/人工首响耗时',
  last_msg_time        DATETIME,
  close_reason         VARCHAR(32),
  create_time          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  update_time          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_group (group_id),
  KEY idx_user_status (user_account_id, status),
  KEY idx_last_msg (status, last_msg_time)  -- 超时扫描
);

-- 消息记录
CREATE TABLE cs_message (
  id          BIGINT PRIMARY KEY AUTO_INCREMENT,
  session_id  BIGINT      NOT NULL,
  msg_id      VARCHAR(64) NOT NULL COMMENT '环信消息ID（幂等）',
  sender_id   VARCHAR(64) NOT NULL,
  sender_type VARCHAR(8)  NOT NULL COMMENT 'USER/AI/AGENT/SYSTEM',
  msg_type    VARCHAR(8)  NOT NULL COMMENT 'TXT/IMG/FILE',
  content     TEXT,
  biz_type    VARCHAR(24) DEFAULT NULL COMMENT 'TRANSFERRED/QUEUE_UPDATE/CLOSED',
  create_time DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_msg (msg_id),
  KEY idx_session (session_id, id)
);

-- 熟客关系
CREATE TABLE cs_familiar_relation (
  id              BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id         VARCHAR(64) NOT NULL,
  agent_id        VARCHAR(64) NOT NULL,
  serve_count     INT NOT NULL DEFAULT 1,
  last_serve_time DATETIME NOT NULL,
  UNIQUE KEY uk_user_agent (user_id, agent_id)
);

-- 转人工记录
CREATE TABLE cs_transfer_record (
  id          BIGINT PRIMARY KEY AUTO_INCREMENT,
  session_id  BIGINT NOT NULL,
  from_type   VARCHAR(8)  NOT NULL DEFAULT 'AI',
  to_agent_id VARCHAR(64),
  trigger     VARCHAR(16) NOT NULL COMMENT 'KEYWORD/AI_TRANSFER/FAILOVER/MANUAL/VIP',
  result      VARCHAR(16) NOT NULL COMMENT 'SUCCESS/QUEUED/FAILED',
  create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_session (session_id)
);

-- AI 厂家配置
CREATE TABLE cs_ai_provider (
  id            BIGINT PRIMARY KEY AUTO_INCREMENT,
  provider_code VARCHAR(32) NOT NULL,
  name          VARCHAR(64) NOT NULL,
  base_url      VARCHAR(255) NOT NULL,
  app_key       VARCHAR(255),
  app_secret    VARCHAR(255) COMMENT 'AES 加密存储',
  timeout_ms    INT NOT NULL DEFAULT 8000,
  retry_times   INT NOT NULL DEFAULT 1,
  weight        INT NOT NULL DEFAULT 100,
  status        TINYINT NOT NULL DEFAULT 1,
  extra_json    JSON,
  create_time   DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_status_weight (status, weight)
);

-- 分配策略配置（单行全局 + 组覆盖 JSON）
CREATE TABLE cs_assignment_strategy (
  id          BIGINT PRIMARY KEY AUTO_INCREMENT,
  scope       VARCHAR(16) NOT NULL COMMENT 'GLOBAL/GROUP',
  group_id    BIGINT DEFAULT NULL,
  config_json JSON NOT NULL,
  update_by   VARCHAR(64),
  update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_scope_group (scope, group_id)
);

-- 满意度评价
CREATE TABLE cs_evaluate (
  id         BIGINT PRIMARY KEY AUTO_INCREMENT,
  session_id BIGINT NOT NULL UNIQUE,
  score      TINYINT NOT NULL COMMENT '1-5',
  tags       VARCHAR(255),
  comment    VARCHAR(500),
  create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 快捷回复
CREATE TABLE cs_quick_reply (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  group_name VARCHAR(64), title VARCHAR(64) NOT NULL,
  content TEXT NOT NULL, status TINYINT DEFAULT 1
);

-- 转人工词表
CREATE TABLE cs_transfer_word (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  word VARCHAR(64) NOT NULL,          -- 支持 re: 前缀正则
  status TINYINT NOT NULL DEFAULT 1,
  UNIQUE KEY uk_word (word)
);

-- 操作日志
CREATE TABLE cs_op_log (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  operator VARCHAR(64) NOT NULL, action VARCHAR(64) NOT NULL,
  detail JSON, ip VARCHAR(45),
  create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_op_time (operator, create_time)
);

-- 日统计（看板）
CREATE TABLE cs_stat_daily (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  stat_date DATE NOT NULL,
  session_count INT NOT NULL DEFAULT 0,
  ai_resolved   INT NOT NULL DEFAULT 0,
  transferred   INT NOT NULL DEFAULT 0,
  avg_first_response_ms INT,
  avg_score DECIMAL(3,2),
  agent_id VARCHAR(64) DEFAULT NULL COMMENT 'NULL=全局',
  UNIQUE KEY uk_date_agent (stat_date, agent_id)
);
```

### 4. 索引与性能要点

- `cs_message` 按月分表或归档（>500 万行后）；在线查询只查近 90 天；
- 超时会话扫描走 `(status, last_msg_time)` 联合索引 + 分页批处理；
- 统计报表走 `cs_stat_daily` 预聚合，禁止直连明细表；
- 高频读（策略、词表、话术）走 Redis + 本地 Caffeine 二级缓存。
