# 04 · 管理控制台开发文档 — easemob-customer-console

> 面向**客服坐席**与**运营管理员**的 Web 控制台：坐席工作台（实时会话）+ 后台管理（账号/分组/策略/AI 配置/数据看板）。

## 1. 技术栈与工程结构

| 项 | 选型 |
|----|------|
| 框架 | Vue 3 + TypeScript + Vite 5 |
| UI | Element Plus + Tailwind（辅助） |
| 状态/路由 | Pinia · Vue Router（动态路由按角色生成） |
| 图表 | ECharts（vue-echarts） |
| IM | 环信 Web SDK（坐席实时收发消息） |
| 请求 | axios + 统一拦截（Sa-Token 头、错误提示、401 跳登录） |

```
easemob-customer-console
├── src
│   ├── main.ts  App.vue
│   ├── api/request.ts             # axios 实例 + 响应拦截（code!==0 提示）

│   ├── store/user.ts              # 登录态（token / userId / easemobToken）
│   ├── router/index.ts            # 静态路由 + 登录守卫（仅校验登录态，perm 未强制）
│   ├── layouts/AdminLayout.vue    # 侧边栏 + 顶栏
│   └── modules/
│       ├── login/                 # 登录（账号密码 → /admin/auth/login，拿环信 Token 后连接）
│       ├── workbench/             # ★ 坐席工作台（index.vue 单文件两栏布局）
│       ├── account/               # 账号管理

│       │   ├── AgentList.vue      # 坐席账号：列表 + 新增/编辑/删除弹窗
│       │   └── AiAccountList.vue  # AI 账号：列表 + 新增/编辑/删除弹窗
```

## 3. 坐席工作台（核心模块）

### 3.1 工作台布局与数据流

```
┌──────────────────┬───────────────────────────┐
│ 会话列表（左栏）   │        聊天窗口（右栏）      │
│  userAccountId   │  顶栏：当前访客 userAccountId │
│  status          │  消息流（REST 拉取 + IM 增量）│
│                  │  输入框 + 发送 + 结束会话      │
└──────────────────┴───────────────────────────┘
        ▲ GET /admin/workbench/sessions（定时 10s 轮询）
        ▲ GET /admin/workbench/messages/{sessionId}
        ▲ POST /admin/workbench/send（REST 代发）
        └──────── 环信 SDK onTextMessage 增量推送（当前会话去重追加） ────────┘
```

> 【现状：未实现】三栏布局（用户资料侧栏）、等待队列 Tab、抢单、转接弹窗、快捷回复面板、未读红点/角标。

### 3.2 坐席上下线（联动分配服务）

```ts
// 登录后：login/index.vue 调 loginEasemob(userId, easemobToken) 建立环信长连接
// 进入工作台 onMounted：
await request.post('/admin/workbench/online')   // 后端：写 cs:agent:online，进入分配候选
```

> 坐席进入工作台即自动上线；关闭浏览器由心跳超时兜底下线。【现状：未实现】主动下线按钮、`goOffline` 流程。

### 3.3 消息收发

- **收**：环信 SDK `onTextMessage` → 按 `groupId` 匹配会话列表；命中当前会话且未重复（msgId 去重 + 内容/时间比对）则追加到消息流；列表外的消息触发会话列表刷新；
- **发**：当前仅 **REST 代发** 模式：`POST /admin/workbench/send`（后端以坐席身份经环信发群消息并落库），发送后重新拉取消息；
- **历史**：选中会话时 `GET /admin/workbench/messages/{sessionId}?limit=50` 全量拉取。
- 【现状：未实现】SDK 直发模式（方案 A）、快捷回复、图片/表情、已读回执。

### 3.4 结束会话

```ts
await request.post('/admin/workbench/close', { sessionId, reason: 'AGENT_CLOSE' })
// 后端：会话置 CLOSED、释放坐席负载、发结束语（ext.bizType=CLOSED）并解散环信群
```

> 【现状：未实现】抢单（`/admin/workbench/claim`）、转接（`/admin/workbench/transfer`）前端入口；后端 transfer 接口当前等价于关闭会话（见 06 文档）。

### 3.5 用户资料侧栏

【现状：未实现】`GET /admin/workbench/user/{userId}` 后端已提供但返回空，前端无侧栏 UI；历史会话/内部备注未开发。

## 4. 分配策略配置页

```
全局默认策略:  ( )平均分配  (●)熟客优先  ( )指定ID
熟客关系有效期: [ 30 ] 天
无坐席时:  (●)AI 兜底+排队   ( )直接留言
排队上限: [ 50 ] 人     单坐席接待上限: [ 5 ] 会话

技能组覆盖（表格）：
┌──────────┬────────────┬────────────┐
│ 技能组    │ 策略        │ 特殊参数    │
├──────────┼────────────┼────────────┤
│ A组-售前  │ 平均分配    │ -          │
│ B组-VIP  │ 指定ID     │ 专属坐席池  │
└──────────┴────────────┴────────────┘
```

> 【现状】前端表单已落地（`assignment/index.vue`：默认策略/熟客有效期/排队上限/无坐席策略/单坐席上限）；后端 `GET/PUT /admin/assignment/strategy` 为固定返回的 stub，未真正读写策略表，技能组覆盖表格未实现。Redis 策略缓存未启用。

## 5. AI 管理页

### 5.1 厂家配置（ProviderList）

| 列 | 说明 |
|----|------|
| 厂家 | providerCode（OPENAI / DIFY）+ 名称 + 模型 |
| 地址 | baseUrl |
| 权重 | 路由优先级（chatWithFailover 按权重排序） |
| 状态 | 启用/停用 |
| 操作 | 编辑 / 删除 / **连通性测试** |

- 新增/编辑弹窗：厂家类型、名称、baseUrl、API Key（编辑时空白表示不修改）、模型与系统提示词（存 `extra_json`）、超时、重试、权重、状态；
- 连通性测试：`POST /admin/ai/provider/test` → 后端用该配置（`AiRouteService.chatWith` 按厂商直连，不走权重路由）发一条测试问题，弹窗展示成功/耗时/答案摘要；
- 密钥保存：前端 HTTPS 传输，后端入库（当前为明文存储，AES 加密未实现）；
- 厂家适配器：`OpenAiAdapter`（OpenAI 兼容协议，适用 OpenAI 官方 / DeepSeek / Moonshot / 阿里云百炼兼容模式等）、`DifyAdapter`。

### 5.2 转人工词表与兜底话术

- 词表（`TransferWords.vue`）：读 `cs_transfer_word` 表，PUT 整体保存字符串数组；命中即转人工；
- 【现状：未实现】`re:` 正则前缀支持、兜底话术/欢迎语/排队话术独立配置页（当前欢迎语/结束语由服务端代码内置）。

## 7. 关键页面联调要点

| 场景 | 前端依赖 | 后端接口/事件 |
|------|----------|----------------|
| 坐席登录连接 IM | 环信 Token（登录接口返回） | `POST /admin/auth/login` |

| 账号 CRUD | 弹窗 | `/admin/account/**`（见 06 文档） |
